# Writing docs

- Prefer many short, focused files over one long file. Create a new file whenever a topic can stand on its own.
- Name files in kebab-case, e.g. `git-workflow.md`.
- Link related files instead of repeating content.
- Files must pass the Markdown CI in [`.github/workflows/markdown.yml`](../.github/workflows/markdown.yml). Aim well below its line limit.
