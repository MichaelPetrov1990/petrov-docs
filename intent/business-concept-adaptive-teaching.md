# Business concept: adaptive teaching

## Example

### Learning objective

Year 2 Maths:

> Add two 2-digit numbers crossing 10.

Before the lesson, pupils complete a short diagnostic.

The platform might identify:

```text
Amelia
✓ Number bonds secure
✓ Place value secure
✓ Adding ones secure
✓ Exchanging secure

Suggested response:
- Same learning objective
- Minimal scaffold
- Earlier reasoning/problem-solving challenge
```

```text
Ben
✓ Number bonds secure
✓ Place value secure
✗ Exchanging

Suggested response:
- Same learning objective
- Explicit worked example
- Place-value counters
- Scaffold first two questions
- Remove scaffold if secure
```

```text
Charlie
✗ Number bonds secure
✓ Place value secure

Suggested response:
- Same learning objective
- Number-bond prompt
- Manipulatives available
- Teacher check-in before independent work
```

All pupils are still working towards the same objective.

## Adaptive teaching rather than differentiation

The product should **not** be positioned as:

> AI-generated differentiated worksheets.

That risks recreating the old:

```text
Low group → easy worksheet
Middle group → normal worksheet
High group → hard worksheet
```

model.

Instead, position it as:

> Adaptive teaching powered by formative assessment.

The system should maintain the same ambitious learning objective while adapting:

- scaffolding
- representations
- worked examples
- language demands
- number of steps shown
- manipulatives
- prompts
- sentence stems
- question sequencing
- teacher check-ins
- depth of reasoning
- when scaffolds are removed

A better output might therefore be one core task with optional adaptations.

Example:

```text
CORE TASK
Everyone completes Q1–Q8

Adaptive support available:
□ Number line
□ Worked example
□ Sentence stem
□ Place-value counters
□ Partially completed first question
□ One question displayed at a time

Adaptive challenge:
□ Explain your reasoning
□ Spot the mistake
□ Prove it
□ Find another method
```

The system knows which pupils are likely to need which adaptations, but the teacher remains able to override them.

## Ofsted / DfE alignment

The concept fits adaptive teaching better than traditional ability-group differentiation.

Current guidance emphasises:

- formative assessment
- adapting teaching in response to pupil understanding
- maintaining ambitious expectations
- removing barriers to learning
- avoiding unnecessary permanent task differences between groups

Therefore the platform should focus on helping teachers change the **support**, not automatically lower the **learning goal**.

Potential product language:

> Help every pupil access the same ambitious learning objective through evidence-informed adaptations.

## Misconception diagnosis

A major opportunity is going beyond simple scores.

Weak product:

```text
Ben scored 3/5.
```

Better product:

```text
Ben's likely misconception:
When crossing ten he adds the tens correctly
but loses the exchanged ten.
```

Then:

```text
Recommended adaptation:
- Model exchanging explicitly
- Use place-value counters
- Provide a scaffold for Q1–Q2
- Check understanding after Q2
- Remove scaffold if secure
```

This is closer to genuine adaptive teaching.

Eedi is an interesting reference product because it focuses heavily on identifying *why* a pupil has answered incorrectly.
