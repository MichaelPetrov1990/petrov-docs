# Intent

Intent documents for the adaptive teaching platform: a primary-school product that uses formative assessment to recommend adaptive-teaching actions for the physical classroom.

These documents are a starting reference, not a final spec. Expect them to change as the intent is refined.

## Business concept

The wider product vision.

1. [Overview](business-concept-overview.md): core idea, problem, existing market, product opportunity
2. [Adaptive teaching](business-concept-adaptive-teaching.md): worked example, adaptive teaching vs differentiation, Ofsted/DfE alignment, misconception diagnosis
3. [Pupil context and privacy](business-concept-pupil-context-and-privacy.md): MIS integration, pupil model, SEND, teacher control, data protection
4. [Positioning](business-concept-positioning.md): teacher view, core proposition, business positioning, competitive advantage
5. [Roadmap and risks](business-concept-roadmap-and-risks.md): MVP, phase 2, longer term, business model, biggest risks
